# ADR-036: 브랜드 accent를 amber에서 aubergine으로 교체하고 시각 스케일을 전면 개정한다 [superseded]

**상태**: Superseded — ADR-037이 코드 구현 착수 전 문서 단계에서 이 방향을 대체했다. 이 ADR은 커밋 전에 폐기되어 전문은 git history에 없다(작성 당시 상세: 색상 8항목 개정안 — aubergine `#4a154b`·link blue 분리·canvas tint·pastel-mesh·pill radius 전면·Slack 관찰 elevation·Inter 도입·모션 역추정 계획).
**한 줄 요약**: Slack 관찰값 기반 aubergine accent·pill radius·pastel-mesh gradient로 시각 스케일 전면 개정을 결정했으나, 코드 구현 전 재사용성·표준화 우선순위가 확인되어 shadcn preset 체계(ADR-037)로 방향이 바뀌며 폐기됐다.
